Final year project Team of 3 Monash University

Custom Orthopaedic Soles using Unsupervised Learning

Challenge
Turn raw plantar pressure measurements into a manufacturable, customised sole.
What we built
An end-to-end workflow from raw pressure data to a 3D-printable sole, using unsupervised learning (K-means) to find regions of similar pressure. I was the only Mechatronics student on the team.
Problems solved
Material allocation on the pressure map was wrong, so we added parameters and methods that follow accepted orthotic design practice, which gave a significant improvement. With no existing quantitative benchmark, we defined our own measures of improvement. They indicate gains without being a complete definition.
Scope control
Cut planned feature additions to focus on what mattered most: reducing foot pressure.
Outcome
5 TPU prototypes printed and validated on a Pedar in-shoe system, measuring pressure change across the gait cycle. Built skills in technical documentation, test planning and iterating from earlier mistakes.
  • Python
  • K-means
  • SolidWorks
  • TPU 3D printing
  • Pedar
